# AIDD Daily Paper Bot

每天从固定期刊白名单、bioRxiv 和 ChemRxiv 获取候选论文，通过筛选和查重后，生成中文摘要并写入 Notion。

## 论文范围

唯一准入原则：**AI 方法直接用于药物发现或设计，并与论文主要贡献关联。** 不使用相关性打分或分层展示。

保留以下任务：

- 药物分子生成、设计、先导优化。
- AI 对接、虚拟筛选、蛋白–配体结合与亲和力预测。
- 药物活性、选择性、毒性、ADME/ADMET 等性质预测。
- 治疗性蛋白、抗体、多肽及靶点结合分子的设计或性质预测。

AI 设计论文包含化学合成、细胞或动物实验验证，仍可入库。

不再单独收录传统 CADD、普通分子动力学、力场、结构解析、电子密度重建、一般蛋白折叠、实验机制、材料与仪器研究。AI 材料设计、蛋白/多肽水凝胶和一般蛋白模型水印方法也不在范围内。

## 筛选方式

标题和摘要中必须同时有 AI 方法、药物任务及相关研究对象的证据。标题明确说明 AI 药物任务时直接通过；否则要求摘要中的贡献句提供相关方法证据。模型名字只作为 AI 方法证据，不能独立触发入库。药物或 AI 只在背景中出现，不应单独成为收录理由。

这是基于文本规则的筛选，不能完全替代人工阅读。没有摘要且标题缺乏药物任务证据时采用保守判断。完整任务关键词及方法模式见 `daily_paper.py` 的关键词区和 `match_core_keywords`。

## 来源和查重

正式期刊通过 Crossref 按 ISSN 查询；白名单仍为代码中的 21 本期刊。另查询 bioRxiv、ChemRxiv；未接入 arXiv。每次回看 4 天，两个预印本平台每次各最多新增 5 篇。更正、撤稿等内容跳过，按 DOI、URL、标题查重。

## 离线验证

```sh
python -m py_compile daily_paper.py
python -m unittest discover -s tests -v
```

测试无需 API 密钥，不连接 Notion。历史回归集覆盖 79 篇真实候选，其中新范围保留 23 篇、排除 56 篇。`previous_keep` 记录上一版较宽范围的判断，便于对照。
